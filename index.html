How promoted proxy works

If a 2025-26 opponent wasn't in PL last season (e.g. Sunderland), we compare the fixture vs the relegated team of equivalent position: Leeds (Champ 1) → Leicester (PL 18), Burnley (2) → Ipswich (19), Sunderland (3) → Southampton (20). This mapping is auto-generated in public/data/mapping.json by scripts/sync.mjs from computed tables and flagged if mismatched. Change file to correct.
